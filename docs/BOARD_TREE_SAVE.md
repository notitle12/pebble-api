# 게시판 초안 저장 — API #90 / Web #47

게시판 관리에서 추가·이름·삭제·드래그는 프론트 초안이다. 저장을 누르면 PUT /members/me/boards가 변경 전체를 하나의 트랜잭션으로 적용한다. 회원 행 잠금, 소유권, baseline 최신값 비교, 깊이/중복 검증을 수행하고 삭제 시 PostBoardService를 통해 글의 게시판 참조만 해제한다.

DB 스키마와 Secret 변경은 없다. 기존 개별 CRUD는 다른 화면과의 호환성을 위해 유지한다. 프론트보다 API를 먼저 배포한다. 공개 Swagger 활성화나 권한 완화는 하지 않는다. HTTP PUT USER endpoint를 등록하면 같은 엔드포인트 카탈로그에서 CORS가 자동으로 구성된다.

base와 최종 boards 입력·오류·제한은 API.md 5.4.1이 계약 원본이다. 타 탭이나 개별 CRUD가 먼저 저장했으면 409로 전체 저장을 거부한다. 호출자 데이터 덮어쓰기나 원격 비밀 출력 없이 검증한다.

검증: 격리 임시 PostgreSQL·Redis에서 전체 520개 테스트와 bootJar 성공. 신규 부모·부모/자식 반전·삭제 후 글 보존·타인 ID/중복/깊이/JSON 필드 거부·PUT CORS·회원 잠금 아래 stale baseline 거부·중간 쓰기 실패 롤백을 검증했다. 반복 테스트로 누적된 임시 Redis 로그인 제한은 이 작업의 테스트 컨테이너를 새로 생성한 뒤 최종 전체 테스트로 확인했다. 운영 비밀 설정은 읽지 않았다.
