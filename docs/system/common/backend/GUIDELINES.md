# 백엔드 공통 작업 기준

특정 언어·프레임워크·서비스에 종속되지 않는 기준이다.

- 요청 검증, 유스케이스 조정, 핵심 업무 규칙, 외부 시스템 구현의 책임을 구분한다. 필요하지 않은 계층·인터페이스·이벤트는 만들지 않는다.
- 인증·역할·소유권·리소스 상태의 최종 검증은 서버에서 수행한다. 클라이언트가 전달한 ID나 Role만으로 권한을 부여하지 않는다.
- 트랜잭션 범위와 외부 호출의 실패 영향을 확인한다. 동시성·무결성이 필요한 변경은 해당 경계의 동작을 검증한다.
- Entity나 내부 비밀을 API로 그대로 노출하지 않는다. 성공·오류·페이지·식별자 계약은 프로젝트가 정한 형식을 따른다.
- DB·캐시·저장소 변경은 기존 저장·삭제·복원 정책을 확인한다. 마이그레이션과 관련 문서를 함께 관리한다.
- 언어 버전·주입 방식·패키지 이름·토큰 수명·HTTP 상태는 프로젝트 문서와 실제 코드에서 확인한다.
- 변경한 동작에 필요한 테스트를 실행한다. 대역 검증과 실제 외부 서비스 검증을 구분한다.
